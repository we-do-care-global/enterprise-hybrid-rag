Reciprocal Rank Fusion · how the two rankings combine
# fused score for document d
RRF(d) = Σ i ∈ {bm25, dense} 1 / (k + ranki(d))
# standard constant, insensitive to score scale
k = 60

Why rank, not score. BM25 and dense similarity live on different scales. RRF consumes only each list's rank position, so neither scorer can dominate the fused result.

Documents missing from one list contribute zero from that list — the other list still carries them. Configurable k controls how quickly rank contributions decay.
